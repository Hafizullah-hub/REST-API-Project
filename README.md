# CodeCraftHub Backend API (Node.js & Express)

A lightweight RESTful API for managing personalized developer learning courses. Data is persisted locally in `courses.json` with zero database setup required.

## Prerequisites
- **Node.js** (v16 or higher)
- **npm**
- **curl** (for testing endpoints)
